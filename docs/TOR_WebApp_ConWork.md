## 📄 [หน้า 2] รายละเอียดขอบเขตของงาน (TOR)

```text
       รายละเอียดขอบเขตงานวิจัยและพัฒนาผลิตภัณฑ์พร้อมบรรจุภัณฑ์ต้นแบบเว็บแอปพลิเคชัน
1. วัตถุประสงค์ของการจัดจ้าง
   1.1 เพื่อพัฒนาระบบเว็บแอปพลิเคชัน (ระบบ ConWork) สำหรับใช้ในการทดสอบตลาด ให้กับทีม GentleCare
       ผู้ประกอบการภายใต้แผนงานการสร้างผู้ประกอบการรายใหม่ในภูมิภาค ประจำปีงบประมาณ พ.ศ. 2569
   1.2 เพื่อจัดหาและเช่า Cloud Server / Database Service เป็นเวลา 1 ปี พร้อมใบรับรอง SSL Certificate
   1.3 เพื่อออกแบบระบบฐานข้อมูล (Database Schema) และหน้าจอใช้งาน (UI/UX Design)
   1.4 เพื่อกำหนดสิทธิ์ความปลอดภัยข้อมูล (Role-Based Access Control)
   1.5 เพื่อส่งมอบซอร์สโค้ด (Source Code) เอกสารคู่มือ จัดอบรมการใช้งาน และบำรุงรักษาระบบเป็นเวลา 1 ปี

2. ขอบเขตงานพัฒนาเว็บแอปพลิเคชัน (Web Application) ระบบ "ConWork"
   2.1 การจัดหาและเช่าระบบเซิร์ฟเวอร์ (Cloud Server & Infrastructure Setup 1 ปี)
       1) จัดหาและเช่า Cloud Server / Database Service (เช่น Supabase / AWS / Vercel) เป็นเวลา 1 ปี
       2) ดำเนินการติดตั้ง Domain Name และ SSL Certificate (HTTPS)
       3) จัดทำระบบสำรองข้อมูลอัตโนมัติ (Automated Backup) อย่างน้อยสัปดาห์ละ 1 ครั้ง

   2.2 การออกแบบและจัดสร้างโครงสร้างฐานข้อมูล (Database Schema)
       1) ออกแบบ Database Schema รองรับข้อมูล Profiles, Companies/Workspaces, Subscriptions ฯลฯ
       2) กำหนดสิทธิ์และความปลอดภัยในการเข้าถึงข้อมูล (RLS Policies)
       3) จัดทำและนำเข้าข้อมูลเริ่มต้น (Seed Data / Initial Setup)

   2.3 การออกแบบ UI/UX (Responsive Design)
       1) ออกแบบ Wireframe / Mockup รองรับทั้ง Desktop และ Mobile
       2) สามารถแก้ไขแบบร่าง UI/UX ได้ไม่เกิน 3 ครั้ง

   2.4 พัฒนาฟังก์ชันการทำงานหลัก (Core Features)
       1) ระบบสมัครสมาชิก ยืนยันตัวตน และจัดการโปรไฟล์ (Authentication)
       2) ระบบบริหารจัดการพื้นที่ทำงานและสมาชิก (Company Workspace & Team)
       3) ระบบจัดการแผนสมัครสมาชิก (Subscription Plans)
       4) ระบบแสดงผลสถิติและรายงานสรุป (Dashboard & Reports)

3. การส่งมอบงาน ระยะเวลา และไทม์ไลน์ (ภายใน 40 วัน นับถัดจากวันลงนามในสัญญา)
   3.1 แผนการส่งมอบงาน:
       - ไฟล์แผนผังฐานข้อมูล (ER Diagram) และภาพร่าง UI/UX
       - ระบบเว็บแอปพลิเคชัน ConWork บน Cloud Server พร้อมใช้งาน (เช่า Server 1 ปี)
       - สิทธิ์การเข้าถึง Source Code ทั้งหมดบน Git Repository 100%
       - เอกสารคู่มือการใช้งาน (PDF) และจัดอบรมการใช้งาน 1 ครั้ง
       - ใบรับประกันระบบและบำรุงรักษาระบบ (Maintenance 1 ปี)
```
